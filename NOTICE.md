# Notices

This project is an independent public-source screening tool. It is not an
official airport, government, military, legal, engineering, or acoustic
assessment.

Map tiles and geocoding are powered by OpenStreetMap-related services. Map
data is copyright OpenStreetMap contributors and available under the Open
Database License. See:

- <https://www.openstreetmap.org/copyright>
- <https://operations.osmfoundation.org/policies/nominatim/>

The colored corridors are heuristic screening bands derived from public
information and manual assumptions. They should be verified on site before any
housing decision.
